Activation functions play an important role in deep neural networks by introducing the non-linearity needed to learn complex input patterns. Smooth activation functions such as Swish, GELU, and Tanhexp are attractive for modern neural models, but their direct hardware implementation is expensive because they involve non-linear and transcendental operations. Supporting several such functions in hardware usually requires separate lookup tables, piecewise-linear units, or polynomial approximation blocks, which increases area and power.
This work proposes a synthesizable HDC-inspired unified activation accelerator for Swish, GELU, and Tanhexp. The design represents inputs, activation-function identifiers, and output classes using binary hypervectors. Instead of storing a separate 1760-bit hypervector for every symbol, a shared 1760-bit base hypervector is reused through deterministic shifted slicing to generate the required codebook vectors. The activation mapping is captured using a single pre-trained super-vector, which is generated offline through an error-driven HDC learning procedure and embedded into the RTL.
For inference, the quantised input and selected function are combined using XOR-based binding. The resulting representation is compared with the output dictionary using Hamming-distance nearest matching. To limit hardware cost, the 1760-bit operation is processed as 22-bit chunks over 80 cycles, allowing the popcount and distance-accumulation hardware to be reused. Boundary-aware output reconstruction is used for positive and out-of-range inputs, reducing the required active approximation range.
The proposed design is validated through RTL simulation, synthesis analysis, and CNN-level accuracy evaluation using the generated activation outputs. While the HDC-based representation requires more area than highly optimised polynomial activation units, it avoids multipliers and dividers in the inference datapath and provides a unified hardware structure for multiple smooth activation functions.
All design files are made freely available for easy adoption and further usage to the designers and research community.
